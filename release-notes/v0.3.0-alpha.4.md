# Lasper v0.3.0-alpha.4

This pre-release replaces broad privileged commands and paths with typed operations, while expanding storage and bootstrap behavior around the systemd-nspawn runtime contract.

## Bootstrap profiles and policy

- Add typed, method-scoped profiles for debootstrap, pacstrap, and DNF5, including independent editable `default` profiles.
- Add provider-specific policy for release and package signatures, dependency behavior, repository selection, metadata refresh, documentation, candidate selection, keyrings, mirrorlists, and host integration.
- Install provider-specific baseline packages required by systemd-nspawn sessions. Profile packages are additive and deduplicated.
- Probe debootstrap for the supported `--no-check-sig`/`--no-check-gpg` and `--force-check-sig`/`--force-check-gpg` spellings before enforcing signature policy.
- Keep DNF5 repository authority explicit and typed. DNF5 profiles select the host repository configuration rather than accepting arbitrary repository paths or command flags.

## Storage and image import

- Rework managed directory, Btrfs subvolume, and raw image storage as typed elevated operations with validated machine names and derived host paths.
- Expand the raw image backend with canonical `.raw` publication, sparse FD copying, partition-table and whole-filesystem layouts, automatic root partition detection, and typed manual partition selection.
- Unify local and remote Tar/Raw sources behind one image importer. The unprivileged caller opens or downloads the source and passes only a file descriptor to the elevated daemon.
- Detect gzip, xz, zstd, and bzip2 from file content, decompress into anonymous temporary files, and reject failed or corrupt streams before privileged import.
- Derive Tar extraction targets from typed managed rootfs identifiers. Validate imported Raw images with `systemd-dissect` and remove rejected images.

## Safety and reliability

- Route service overrides, NVIDIA state and staging, device policy, rootfs mutations, user provisioning, and managed storage through narrow typed daemon requests.
- Reject path traversal, unknown authority fields, unsafe symlinks, invalid machine names, option-shaped packages, and container credential injection before privileged execution.
- Remove several shell-mediated provisioning paths and constrain the remaining command inputs to validated data arguments.
- Improve deployment rollback, machine start observation, network enablement, Wayland runtime binding, and NVIDIA cleanup behavior.

## UI and configuration

- Document the bootstrap profile schema and expose provider policies in the source wizard without an implicit debootstrap suite.
- Add raw image filesystem, partition-table, and root partition selection controls to the creation wizard.
