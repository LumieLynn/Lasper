# Lasper v0.3.3

Lasper is a terminal interface for managing systemd-nspawn containers, creating images, and running container applications alongside the host desktop.

## Container management

- Browse running machines and stored images, start containers, and control their lifecycle through D-Bus or systemd tools.
- Inspect machine and image overviews, systemd properties, unit files, drop-ins, and journal logs.
- Run the TUI as a regular user or use `lasper -e` to perform privileged operations through a separate root daemon.

## Image creation

- Create Debian, Ubuntu, Arch, and Fedora images with `debootstrap`, `pacstrap`, or `dnf5`; import local or remote tar and raw images, clone existing images, and pull OCI application images on supported systemd versions.
- Choose directory, Btrfs subvolume, or raw-image storage in the creation wizard, with network and host-integration settings.
- Save bootstrap defaults and named profiles in `lasper.toml`. The wizard reports invalid profiles and missing bootstrap tools, including `pacman` for pacstrap.

## Host integration

- Configure Wayland and X11 socket binds from the TUI, with current-display indicators and access checks for selected guest users. X11 supports individual sockets and the complete socket directory.
- Open display-enabled shells with `lasper shell user@machine`, or run desktop applications with `lasper launch`. Wayland follows the current configured display; X11 is enabled explicitly with `--with-x11`.
- Track X11 access granted by Lasper and reclaim it when the associated machine instance ends.
- Configure NVIDIA passthrough using generated CDI data or an existing host CDI document, with driver-state updates for managed containers.

## Embedded terminals

- Open multiple terminal tabs per container with the rio-vt terminal core, scrollback, resizing, and host-terminal color and cursor handling.
- Browse output in NORMAL mode and select text in character, line, or block VISUAL mode. Dragging with the left mouse button in NORMAL mode starts character selection.
- Copy through OSC 52 and keep terminal navigation and input separate from workspace actions.

## Builds and licenses

- Use the Rust 1.99 toolchain and refreshed dependencies, including Ratatui 0.30, zbus 5, and rio-vt 0.5.
- Download glibc or musl binaries for x86_64 and aarch64, with checksums and build-specific toolchain notices.
- Distribute Lasper under GPL-3.0-or-later, with dependency license texts, adapted-source notices, and additional upstream copyright notices included in the release.
