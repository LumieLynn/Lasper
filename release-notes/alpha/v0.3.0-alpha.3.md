# Lasper v0.3.0-alpha.3

This pre-release continues the `v0.3.0-alpha` stabilization work, with emphasis on elevated daemon safety, `.nspawn` configuration integrity, NVIDIA passthrough behavior, and deployment cleanup.

## Changed

- Route Lasper-managed `.nspawn` operations through typed elevated-daemon requests instead of generic privileged file writes.
- Keep ordinary daemon `write_file` operations as atomic one-shot writes; persistent locks are reserved for read-modify-write paths such as `.nspawn` mutation.
- Resolve Wayland socket symlinks after validating the user runtime directory, so WSLg-style `wayland-*` symlink layouts work without relying on WSL-specific environment detection.
- Reduce default log noise from elevated daemon RPC internals and allow detailed diagnostics through `RUST_LOG`.

## Fixed

- Refresh the container dynamic linker cache with `ldconfig` after injecting NVIDIA `ld.so.conf.d` paths, improving WSL host-mirror NVIDIA passthrough where driver libraries live under non-standard paths such as `/usr/lib/wsl/drivers/...`.
- Split container `systemd-networkd` and `systemd-resolved` enablement so a missing or unsupported resolver unit does not prevent networkd from being enabled.
- Remove Lasper-managed `.nspawn` lock files when deleting a container through Lasper.
- Preserve NVIDIA-managed `.nspawn` blocks and unmanaged user sections during GPU passthrough updates.

## Safety

- Validate machine names, signals, terminal sizes, `.nspawn` request payloads, Wayland runtime paths, and NVIDIA bind paths before elevated daemon execution.
- Avoid sending provisioning-only secrets such as root passwords or user passwords through the `.nspawn` daemon protocol.
- Keep persistent lock files for `.nspawn` read-modify-write operations to avoid inode replacement races.

## Validation

- Tested container creation on WSL and normal Arch Linux systems.
- Tested categorized NVIDIA passthrough and WSL host-mirror NVIDIA passthrough.
- Passed the complete test suite, strict Clippy checks, rustfmt, diff whitespace checks, and release build locally before preparing this release.
