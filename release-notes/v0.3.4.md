# Lasper v0.3.4

This release adds run0 elevation and improves display-enabled shells, container lifecycle reporting, daemon cleanup, and wizard memory use.

## Elevation and command-line use

- Start the elevated daemon through run0 and polkit with `--elevate=run0`, or set `elevation-method = "run0"` in `lasper.toml`. Sudo remains the default. Run0 requires systemd 256 or newer.
- Use command-specific help for `lasper shell` and `lasper launch`. Session options work before or after `USER@MACHINE`, and arguments after the guest executable are passed through unchanged.
- Use `-s` or `--systemd-tools` for the systemd command-line backend. The old `-c` and `--cli-mode` aliases have been removed.

## Display-enabled shells

- Register X11 lifecycle cleanup through transient user units, with recovery when a previous cleanup worker exits while a new grant is being created.
- Improve X11 connection retries, display probes, and grant reconciliation after machine changes. Normal active-machine claims no longer produce cleanup warnings.
- Open the TUI without connecting to X11 endpoints during startup. Connections to unresponsive X11 endpoints have bounded waits.
- Prepare Wayland once when opening a shell, preserving failure details and terminal-only fallback behavior.

## Terminals and container management

- Scroll terminal history with the mouse in INSERT mode, show the scroll offset, and return to the live cursor when input resumes.
- Preserve observed D-Bus machine states and distinguish an accepted lifecycle request from a completed state change. Failed requests restore the last observed state.
- Share one refresh loop for machine and image observations, coalescing host changes and retaining explicit refreshes.
- Keep NVIDIA startup preparation and the required manager reload within one privileged operation.

## Memory use and cleanup

- Look up detected GPU names without loading the complete PCI database, reducing memory growth when repeatedly opening the creation wizard.
- Reap long-running terminal and journal sessions without occupying a blocking worker for every session.
- Bound elevated terminal and journal startup, close descriptors on cancelled handoffs, and improve daemon and launcher cleanup during shutdown.
